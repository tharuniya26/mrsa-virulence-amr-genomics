# Computational methods

Run from the repository root. `python -m src.data_acquisition` retrieves the four exact assemblies. `python -m src.genome_qc` streams gzipped FASTA and calculates sum of sequence lengths, GC fraction, number of FASTA records, N50 and N fraction. It rejects duplicate IDs, non-ACGTN characters, empty data and corrupt gzip. Exploratory QC flags an assembly for review if total length is outside 2.5–3.2 Mbp, there are over 20 sequence records or over 1% ambiguous positions. These are a conservative screen for this predefined complete-genome set, not a species-wide universal cutoff. Plasmid records are included in these assembly metrics. Completeness and contamination were not assessed.

`python -m src.amr_analysis` invokes NCBI AMRFinderPlus with `--nucleotide`, `--organism Staphylococcus_aureus` and `--plus`; it writes native TSV per assembly and positive AMR calls. Record the software and database versions emitted by AMRFinderPlus. The wrapper currently requires an installed `amrfinder` executable and a current database. NCBI describes [the curated reference database and HMM approach](https://www.ncbi.nlm.nih.gov/pathogens/antimicrobial-resistance/AMRFinder/). `python -m src.virulence_analysis` extracts explicit VIRULENCE calls from the same output. The selected gene names are exploratory targets, not proof of a complete screen: inspect database coverage before interpreting a non-call as non-detection. Partial or ambiguous hits should be reviewed against native output and sequence context; the parser preserves identity, coverage and method where reported.

`src.comparative_analysis` merges verified metadata and QC, then positive marker lists only when screening files exist. It distinguishes **not assessed** from an empty positive-call list. `src.statistical_analysis` provides selected and QC-pass counts. Wilson intervals are implemented for future fully assessed binary outcomes but not applied to unverified marker screens. No statistical significance tests or prevalence claims are justified for this convenience sample. MLST and SCCmec typing require dedicated tools and cassette-level review; mecA alone is insufficient. Phenotypic comparison requires authentic AST records. A phylogeny is omitted because a robust homologous alignment and recombination-aware design have not been completed.
